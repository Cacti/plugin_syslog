# Syslog 4.1: fixes for cleanup, command execution and collector status

Historical release, published 2023-01-28. [Current releases](https://github.com/Cacti/plugin_syslog/releases).

Syslog 4.1 improves everyday processing and maintenance, with clearer messaging when a Data Collector is offline.

## Highlights

- Correct cleanup-query column selection and database connection handling.
- Fix command execution and runtime issues in traditional-table maintenance.
- Improve the message shown when the Data Collector is offline.

## Compatibility and upgrade checks

The [metadata shipped in v4.1](https://github.com/Cacti/plugin_syslog/blob/v4.1/INFO) declares a minimum Cacti version of **1.2.23**. Follow the [documentation for this tag](https://github.com/Cacti/plugin_syslog/blob/v4.1/README.md) for the matching installation and configuration steps.

Before replacing plugin files, back up the plugin/local configuration and its database together. Apply migration instructions only when they match the version you are upgrading from.

1. For upgrades crossing into Syslog 4.x, review the tagged README’s alert-method change: System Level alerts group matching messages, while per-host behavior requires Host Level alerts.
2. After upgrading, check cleanup against the configured database and exercise a representative alert command with controlled test messages.
