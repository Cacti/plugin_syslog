# Syslog 3.1: import, export and Save-action fixes

Historical release, published 2020-11-10. [Current releases](https://github.com/Cacti/plugin_syslog/releases).

This small maintenance release corrects problems in Syslog import/export workflows and the Save action.

## Highlights

- Clear the export-in-progress indicator when export completes.
- Correct imported alert-rule handling and the Syslog Save action.

## Compatibility and upgrade checks

The [metadata shipped in v3.1](https://github.com/Cacti/plugin_syslog/blob/v3.1/INFO) declares a minimum Cacti version of **1.2.10**. Follow the [documentation for this tag](https://github.com/Cacti/plugin_syslog/blob/v3.1/README.md) for the matching installation and configuration steps.

Before replacing plugin files, back up the plugin/local configuration and its database together. Apply migration instructions only when they match the version you are upgrading from.

1. After upgrading, export a small result set, inspect the completed state, and verify that a representative form saves and an imported alert rule retains its intended definition.
