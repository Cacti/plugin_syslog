# Syslog 2.2: per-rule reprocessing and filtering corrections

Historical release, published 2019-06-17. [Current releases](https://github.com/Cacti/plugin_syslog/releases).

Syslog 2.2 adds per-rule message reprocessing and addresses a broad set of filter, export, compatibility and rule-import problems.

## Highlights

- Reprocess messages for an individual rule.
- Correct device, program, priority and Classic-theme filter behavior.
- Fix Alert Log export, report variables and graph-template import problems.
- Improve database SSL compatibility, predefined installation options and PHP 7.2 handling.

## Compatibility and upgrade checks

The [metadata shipped in v2.2](https://github.com/Cacti/plugin_syslog/blob/v2.2/INFO) declares a minimum Cacti version of **1.2.0**. Follow the [documentation for this tag](https://github.com/Cacti/plugin_syslog/blob/v2.2/README.md) for the matching installation and configuration steps.

Before replacing plugin files, back up the plugin/local configuration and its database together. Apply migration instructions only when they match the version you are upgrading from.

1. After upgrading, use controlled messages to check an individual rule, filter combinations and an exported Alert Log.
2. Review the release’s database SSL and installation options against the versioned documentation before applying them to an existing deployment.
