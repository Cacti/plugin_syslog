# Syslog 2.1: reports, exports and threshold-message improvements

Historical release, published 2018-03-30. [Current releases](https://github.com/Cacti/plugin_syslog/releases).

Syslog 2.1 improves reports and exports, adds hostnames to emailed reports and corrects several statistics, removal-rule and remote-database issues.

## Highlights

- Include hostnames in emailed reports and restore report/export behavior.
- Correct threshold-alert formatting and display of removed records.
- Address statistics-view problems and slowdowns with large program lists.
- Improve remote-database compatibility and local configuration documentation.

## Compatibility and upgrade checks

The [metadata shipped in v2.1](https://github.com/Cacti/plugin_syslog/blob/v2.1/INFO) declares a minimum Cacti version of **1.1.10**. Follow the [documentation for this tag](https://github.com/Cacti/plugin_syslog/blob/v2.1/README.md) for the matching installation and configuration steps.

Before replacing plugin files, back up the plugin/local configuration and its database together. Apply migration instructions only when they match the version you are upgrading from.

1. After upgrading, confirm an emailed report contains the expected hostnames and check exports, statistics and removed-record views.
2. For a separate Syslog database, verify its local configuration is retained and its connection is used.
