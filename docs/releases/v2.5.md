# Syslog 2.5: timestamp integration, filters and re-alert timing

Historical release, published 2019-12-26. [Current releases](https://github.com/Cacti/plugin_syslog/releases).

Syslog 2.5 updates rsyslog timestamp handling and corrects filtering, reporting and notification behavior, including one-minute poller intervals.

## Highlights

- Support the newer rsyslog timestamp format instead of the earlier separate date/time format.
- Fix program filtering, SQL Expression alert rules and international-character handling.
- Correct Re-Alert Cycle behavior with a one-minute poller interval and program synchronization under PHP 7.2.
- Improve report-row formatting and device-status text colors.

## Compatibility and upgrade checks

The [metadata shipped in v2.5](https://github.com/Cacti/plugin_syslog/blob/v2.5/INFO) declares a minimum Cacti version of **1.2.8**. Follow the [documentation for this tag](https://github.com/Cacti/plugin_syslog/blob/v2.5/README.md) for the matching installation and configuration steps.

Before replacing plugin files, back up the plugin/local configuration and its database together. Apply migration instructions only when they match the version you are upgrading from.

1. Upgrading from an earlier version requires reviewing the rsyslog template in this tag’s README and restarting the forwarder after the change. The original documentation warns that messages may be lost during this transition; plan and validate the cutover.
2. After upgrading, send a known message through the forwarder and check its timestamp, program field and notification timing.
