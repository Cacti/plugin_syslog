# Syslog 3.0: alert delivery, retained settings and program-aware reports

Historical release, published 2020-10-28. [Current releases](https://github.com/Cacti/plugin_syslog/releases).

Syslog 3.0 combines alerting and filter fixes with report improvements, interface updates and a published security fix.

## Highlights

- Fix threshold-alert email delivery and Re-Alert Cycle configuration errors.
- Retain saved Syslog tab settings and improve searches for messages that do not contain a term.
- Include Program in report searches and replace image-based interface icons with Font Awesome glyphs.
- Include the previously published security correction identified in the original change list.

## Compatibility and upgrade checks

The [metadata shipped in v3.0](https://github.com/Cacti/plugin_syslog/blob/v3.0/INFO) declares a minimum Cacti version of **1.2.10**. Follow the [documentation for this tag](https://github.com/Cacti/plugin_syslog/blob/v3.0/README.md) for the matching installation and configuration steps.

Before replacing plugin files, back up the plugin/local configuration and its database together. Apply migration instructions only when they match the version you are upgrading from.

1. After upgrading, verify a controlled threshold notification, its re-alert interval, saved filters and a program-based report.
2. Review the original detailed list for the published security identifier.
