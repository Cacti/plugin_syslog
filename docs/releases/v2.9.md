# Syslog 2.9: filter navigation and statistics corrections

Historical release, published 2020-03-28. [Current releases](https://github.com/Cacti/plugin_syslog/releases).

Syslog 2.9 is a focused maintenance release for filter navigation, statistics reporting and translated console text.

## Highlights

- Fix the SQL error encountered when navigating back through Syslog filters.
- Correct statistics reporting and console internationalization issues.

## Compatibility and upgrade checks

The [metadata shipped in v2.9](https://github.com/Cacti/plugin_syslog/blob/v2.9/INFO) declares a minimum Cacti version of **1.2.10**. Follow the [documentation for this tag](https://github.com/Cacti/plugin_syslog/blob/v2.9/README.md) for the matching installation and configuration steps.

Before replacing plugin files, back up the plugin/local configuration and its database together. Apply migration instructions only when they match the version you are upgrading from.

1. After upgrading, test browser Back navigation through a filter change and compare the statistics view with a known sample of incoming messages.
