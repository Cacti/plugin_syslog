# Syslog 2.7: alert-query and separate-database fixes

Historical release, published 2020-03-01. [Current releases](https://github.com/Cacti/plugin_syslog/releases).

This maintenance release addresses database errors in alert processing and loading host data from a separate Syslog database.

## Highlights

- Fix database errors raised by Syslog alerts.
- Restore host-table loading when Syslog and Cacti use different databases.

## Compatibility and upgrade checks

The [metadata shipped in v2.7](https://github.com/Cacti/plugin_syslog/blob/v2.7/INFO) declares a minimum Cacti version of **1.2.8**. Follow the [documentation for this tag](https://github.com/Cacti/plugin_syslog/blob/v2.7/README.md) for the matching installation and configuration steps.

Before replacing plugin files, back up the plugin/local configuration and its database together. Apply migration instructions only when they match the version you are upgrading from.

1. After upgrading, check the configured database connection and confirm host information and a controlled alert are processed correctly.
