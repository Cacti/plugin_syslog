# Syslog 2.6: database selection and statistics-page fixes

Historical release, published 2020-02-22. [Current releases](https://github.com/Cacti/plugin_syslog/releases).

Syslog 2.6 corrects filtering and removal-rule database handling, updates statistics-page rendering and includes a published security correction.

## Highlights

- Fix filtering that incorrectly reports the Cacti host table as missing.
- Use the intended database for removal rules when a separate Syslog database is configured.
- Update statistics-page rendering.
- Include the security correction identified in the original change list.

## Compatibility and upgrade checks

The [metadata shipped in v2.6](https://github.com/Cacti/plugin_syslog/blob/v2.6/INFO) declares a minimum Cacti version of **1.2.8**. Follow the [documentation for this tag](https://github.com/Cacti/plugin_syslog/blob/v2.6/README.md) for the matching installation and configuration steps.

Before replacing plugin files, back up the plugin/local configuration and its database together. Apply migration instructions only when they match the version you are upgrading from.

1. After upgrading, check device filtering, statistics output and removal-rule behavior against the configured database.
