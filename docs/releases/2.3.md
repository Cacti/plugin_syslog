# Syslog 2.3: device filtering and multi-host collection fixes

Historical release, published 2019-06-30. [Current releases](https://github.com/Cacti/plugin_syslog/releases).

Syslog 2.3 improves filtering and multi-host operation, repairs host/program synchronization and includes the published security fix in the original announcement.

## Highlights

- Correct the Alert Log device filter.
- Fix blank pages after collecting messages from multiple hosts.
- Repair synchronization of Syslog Hosts and Programs data.
- Include the security fix listed in the original announcement.

## Compatibility and upgrade checks

The [metadata shipped in 2.3](https://github.com/Cacti/plugin_syslog/blob/2.3/INFO) declares a minimum Cacti version of **1.2.0**. Follow the [documentation for this tag](https://github.com/Cacti/plugin_syslog/blob/2.3/README.md) for the matching installation and configuration steps.

Before replacing plugin files, back up the plugin/local configuration and its database together. Apply migration instructions only when they match the version you are upgrading from.

1. After upgrading, inspect multiple sending hosts, the Alert Log device filter and synchronization of host/program names.
